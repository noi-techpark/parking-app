bolzano-parking-app

Every block below embeds the same bundle with different attributes. Load this after yarn build, e.g. via npx serve . from the repository root.

Defaults

No attributes: every parking, all filters available.

Pinned to two municipalities, single-select

municipalities="Bolzano - Bozen, Meran - Merano" multi-municipality="false"

Real-time sources only, tighter live window

show-static="false" live-max-age="15m" origins="FAMAS, skidata_dynamicdata, Municipality Bolzano"

Fixed viewport, no multi-select at all

center="11.35,46.50" zoom="13" multi-parking="false" multi-origin="false"

Narrow container (mobile layout on a desktop page)

Breakpoints are measured on the element, not the viewport, so a 384 px column gets the sheet layout even here.
